As part of our work at [OfiLibre](/ofilibre/), we generate many custom images for activities, videos, and outreach materials. To avoid relying on heavy or proprietary graphic design tools, we have developed a series of Python scripts that allow us to automate the creation of images with a consistent and professional style.

These tools are based on the [Pillow](https://python-pillow.org) library, also known as PIL (Python Imaging Library), which makes it easy to manipulate images from code.

---

## What can we do with these scripts?

- Create images from graphic templates.
- Insert text in different positions, with different sizes, colors, and fonts.
- Adapt the design according to the number of people or the type of content.
- Use free fonts automatically downloaded from Google Fonts.
- Export the images in PNG format, ready to use on the web or on social media.

## General tool: dynamic image generator

We created a base tool that generates any type of image from a template and a YAML configuration file. This tool allows us to declaratively define all the texts that will appear (for example: title, subtitle, footer), their position, font, color, and alignment.

It is enough to have a base image (for example, a background template) and a `config.yml` file where we define what texts should appear and how.

This has proven especially useful for quickly generating banners, announcements, or cards without the need to open a design program.

For more details, visit [this GitLab repository](https://gitlab.eif.urjc.es/ofilibre/code/), in the folder `automatizacion/edicion-imagenes/`.

However, due to the complexity that filling out the `config.yml` file can entail, especially regarding the position (coordinates) of the elements, we have designed scripts adapted to two frequent use cases in the office: the generation of thumbnails for [cafés](/acciones/cafes) and the generation of thumbnails for materials belonging to [Open Subjects](/acciones/asignaturas_abierto). In these adapted scripts, the coordinates, colors, sizes, and fonts of the elements are already preset, so only their content needs to be indicated.

---

## Case 1: thumbnails for **Café con OfiLibre**

The Café con OfiLibre video series needed thumbnails that were consistent across episodes but flexible enough to adapt to different combinations of presenters and guests.

We developed a script that reads an image template and a configuration file with the title, date, and names, and automatically generates the thumbnail.

Depending on the number of people, the script chooses from several predefined templates. If there are 3 presenters and no guests, a different template is used than if there are 2 presenters and 1 guest.

This allows us to maintain a uniform graphic line with minimal effort and facilitates image generation when there are many consecutive episodes.

For more details, visit [this GitLab repository](https://gitlab.eif.urjc.es/ofilibre/code/), in the folder `automatizacion/miniaturas-cafes/`.

## Case 2: thumbnails for Open Subjects

Another use we gave it was the generation of covers for the videos of our **Open Subjects**, a project that disseminates free teaching materials.

Each cover includes:

- The video title (for example, "Topic 3: Introduction to Digital Marketing").
- The subject name.
- The degree to which it belongs.
- A license section, with mention of Creative Commons and authorship.

All of this is configured in a `config.yml` file, and the script automatically generates a high-quality image with all the information well positioned and with legible typography. In addition, it adapts to any template size, keeping the content centered.

For more details, visit [this GitLab repository](https://gitlab.eif.urjc.es/ofilibre/code/), in the folder `automatizacion/miniaturas-asignaturas-abierto/`.

## Advantages of this approach

- **Time saving:** There is no need to open any editing program, just adjust the texts and run a command.
- **Visual consistency:** All images maintain a unified design.
- **Use of free fonts:** We use Google Fonts typefaces, dynamically downloaded, which avoids relying on proprietary fonts or having to install them manually.
- **Adaptability:** The system can be easily modified for new campaigns or formats.

## How to get started

1. Make sure you have Python 3 installed.
2. Clone the repository or download the scripts.
3. Install the dependencies:

```bash
pip install -r requirements.txt
```

4. Edit the `config.yml` file with the values you want to use.
5. Run the corresponding script:

```bash
python <script_name>.py
```
