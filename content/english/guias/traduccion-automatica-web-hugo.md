# Technical guide: how we added multilingual support (English) to the OfiLibre website

In this guide we explain, step by step, how we implemented English support on the **OfiLibre** website, based on the [`navigator-hugo`](https://github.com/gethugothemes/navigator-hugo) template.

---

## 2. Translated data files

Inside the data/ directory we created a folder data/en/ with the .yml files duplicated but modified for the new language. These files contain exactly the same structure as the original, but with translated text.

For example, the resources.yml file, which generates the same page where the website resources are displayed, but in English.

```yml
enable  : true
topTitle: Material produced by OfiLibre and URJC staff
title   : OfiLibre Resources
item    :

    title   : Presentations
    link    : /pres/

      Slides from talks and workshops previously held by OfiLibre.
```

## 3. Translation of labels and strings

Hugo allows defining translations for static texts (buttons, menus, titles, etc.) using .toml files in the /i18n folder.
We created a file called en.toml with the equivalents for all the texts defined in es.toml.
```toml

other = "Home"

[about]
other = "About"

[activities]
other = "Activities"

[resources]
other = "Resources"
```

## 4. Automated translation with an LLM

To facilitate the translation task, we used a script with a language model (LLM) that automatically translated all texts from Spanish to English.
The script was executed on all relevant .yml and .toml files, and we then manually reviewed the texts to ensure consistency and quality.

You can obtain this script in the [OfiLibre code.](https://gitlab.etsit.urjc.es/ofilibre/code)
