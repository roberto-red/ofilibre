Octave or GNU Octave is a program and programming language for performing numerical calculations. As its name indicates, Octave is part of the GNU project. It is considered the free equivalent of MATLAB. Among the various features they share, it is worth noting that both provide an interpreter, allowing commands to be executed in interactive mode. Note that Octave is not a computer algebra system, like Maxima, but is oriented toward numerical analysis.
