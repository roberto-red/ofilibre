Octave or GNU Octave is a program and programming language for performing numerical calculations. As its name indicates, Octave is part of the GNU project. It is considered the free equivalent of MATLAB. Among several shared characteristics, it can be highlighted that both offer an interpreter, allowing commands to be executed in interactive mode. Note that Octave is not a computer algebra system, like Maxima, but is oriented towards numerical analysis.
