It is a protocol analyzer used to perform analysis and troubleshoot problems in communication networks, for software and protocol development, and as a didactic tool.
* It features all the standard characteristics of a protocol analyzer in a uniquely hollow form. It allows viewing all traffic that passes through a network by setting up the configuration in promiscuous mode.
* It enables examining data or a capture file saved on disk. It includes a complete language for filtering what we want to see and the ability to display the reconstructed flow of a TCP session.
