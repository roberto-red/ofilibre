BEAST is a cross-platform program for the Bayesian analysis of molecular sequences using MCMC. It is entirely focused on rooted phylogenies and time-based measures inferred using strict or relaxed molecular clock models. It can be used as a method to reconstruct phylogenies, but it is also a framework for testing evolutionary hypotheses without conditioning on a single tree topology.
