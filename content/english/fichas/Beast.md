BEAST is a multi-platform program for Bayesian analysis of molecular sequences using MCMC. It is fully oriented towards rooted phylogenies and time-measured inferences using strict or relaxed molecular clock models. It can be used as a method for reconstructing phylogenies, but it is also a framework for testing evolutionary hypotheses without conditioning on a single tree topology.
