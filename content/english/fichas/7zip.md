7-Zip is a free file archiver developed by Igor Pavlov. By default, it uses the 7z file format, also free, (with a .7z extension). This format uses the LZMA and PPMD compression methods (more suitable for texts), developed by its author, and can apply a filter to executables to increase their compressibility. 7z files can be solid, where multiple similar-type files are compressed into a single stream, in order to exploit the combined inherent redundancy of similar files, unlike ZIP, which improves the compression of small file sets.
