7-Zip is a free file archiver developed by Igor Pavlov. By default it uses the free 7z file format (with the .7z extension). This format employs the LZMA and PPMD compression methods (the latter more suitable for text), developed by its author, and can apply a filter to executables to increase their compressibility. 7z files can be solid, where multiple similar files are compressed into a single stream in order to exploit the inherent combined redundancy of similar files, unlike ZIP, which improves the compression of sets of small files.
