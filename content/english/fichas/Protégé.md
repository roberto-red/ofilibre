Protégé is a free open-source editor and a knowledge acquisition system. Like Eclipse, Protégé is a framework for which other projects suggest plugins. The application is written in Java and heavily uses Swing to create its complex interface. Protégé recently has over 100,000 registered users.
Protégé is developed by Stanford University, in collaboration with the University of Manchester.
