## Process

* Slides used in class and detailed program of the subject (including exercises, past exams, practice statements, etc.) written in LaTeX, from which PDF is generated, using GitHub as a collaboration platform among teachers.

* Source code of examples, exercise solutions, practice starters, etc. hosted on GitHub.

* Subject videos built from recordings of classes held via video conferencing, using Teams or OBS to record them. Then, we use Audacity for audio (if necessary), LibreOffice for cover and closing images of the videos, and OpenShot to edit the final videos.
